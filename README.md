# 🎬 CineWave

A modern and responsive movie discovery website that lets users explore trending, popular, and highly rated movies with a clean and interactive user interface.

🌐 **Live Demo:** https://santhoshkumar7-dot.github.io/Cinewave/

---

## 📌 Overview

CineWave is a movie browsing web application designed to provide users with an engaging experience while discovering films. It features a responsive layout, smooth navigation, and visually appealing movie cards that display essential information such as posters, ratings, genres, and release dates.

---

## ✨ Features

- 🎥 Browse trending and popular movies
- 🔍 Search movies by title
- ⭐ View movie ratings and details
- 📅 Display release dates
- 🎨 Modern and responsive UI
- 📱 Mobile-friendly design
- ⚡ Fast loading and smooth user experience

---

## 🛠️ Tech Stack
